🍲 O que é o Ixcondidim?

O Ixcondidim é um filtro Milter de alta performance para Postfix que implementa a especificação aberta Autocrypt Level 1 de forma 100% server-side.

Ele elimina a dor de cabeça do PGP tradicional: os usuários da sua empresa ou homelab enviam e-mails normalmente a partir de qualquer cliente (iPhone, Android, Thunderbird, Webmail) e o servidor cuida de gerar chaves modernas, injetar cabeçalhos e cifrar e-mails sozinho!

✨
Chaves On-The-Fly

Gera automaticamente pares modernos Ed25519 + X25519 para cada conta gerenciada.

🤝
Cifragem Oportunística

Cifra em PGP/MIME automaticamente quando os destinatários possuem suporte ativo.

🔄
Prevenção de Lockout

Se o contato responder de um cliente sem PGP, o Ixcondidim volta para texto claro sem travar a conversa.

🛡️
Palavra de Segurança

Selo anti-phishing oficial no topo de e-mails decifrados, impossível de ser forjado.

📬 Exemplo do Banner com Palavra de Segurança

Ao receber um e-mail cifrado em PGP/MIME, o Ixcondidim decifra a mensagem para que ela seja lida em qualquer Webmail ou aplicativo, estampando a palavra secreta combinada na configuração:

🔒 [Ixcondidim: Mensagem PGP Decifrada pelo Servidor]
Palavra Secreta de Validação: [EscondidinhoPraiano]
Remetente: amigo@quiosque.net
Assinatura Digital: ✓ VÁLIDA (Assinatura confirmada)
ID da Chave: 4f8a91c23da75b10 (Ed25519)

* Tentativas de simulação desse banner por mensagens de spam ou phishing em texto claro são desarmadas automaticamente pelo motor de sanitização anti-spoofing.

🚀 Instalação Rápida no Postfix

1. Compile e instale o binário:

git clone https://codeberg.org/lumenpink/ixcondidim.git
cd ixcondidim
cargo build --release
sudo cp target/release/ixcondidim /usr/local/bin/

2. Instale o serviço Systemd e configuração:

sudo mkdir -p /etc/ixcondidim /var/lib/ixcondidim/keys /var/lib/ixcondidim/peers /run/ixcondidim
sudo cp deploy/ixcondidim.example.toml /etc/ixcondidim/ixcondidim.toml
sudo cp deploy/ixcondidim.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now ixcondidim

3. Plugue no Postfix (/etc/postfix/main.cf):

# Integração de Milters (Ordem: Papéli -> Ixcondidim -> OpenDKIM)
smtpd_milters = unix:/run/papeli/papeli.sock, unix:/run/ixcondidim/ixcondidim.sock, unix:/run/opendkim/opendkim.sock
non_smtpd_milters = $smtpd_milters

milter_default_action = accept
milter_protocol = 6

4. Reinicie o Postfix:

sudo systemctl restart postfix

⚙️ Exemplo de Configuração (ixcondidim.toml)

[server]
listen = "unix:/run/ixcondidim/ixcondidim.sock"

[storage]
keys_dir = "/var/lib/ixcondidim/keys"
peers_dir = "/var/lib/ixcondidim/peers"

[default]
prefer_encrypt = "mutual"
auto_generate_keys = true
auto_add_header = true
auto_collect_peers = true
encryption_mode = "opportunistic"
decrypt_incoming = true
security_word = "EscondidinhoPraiano"

[domains."kiridu.net"]
prefer_encrypt = "mutual"
security_word = "KiriduPrivacidade"
